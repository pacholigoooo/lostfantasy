皇家烈焰研究手稿

日符「皇家烈焰」：球形领域的供能、输运与热响应
帕秋莉·诺蕾姬

约定：物理量采用SI单位。灵力维持的空间边界单独列为约束，不作为电磁定律的推论。

散页一：符号与供能

设领域中心为O，作用半径为R，中心发光体半径为r。r与R独立：发光体尺寸不等于作用范围。

姿态条件：双臂抬起并向外展开；聚能中心位于头顶上方。双手作为引导端，随展开角度改变输入方向，中心与视线保持错开。

设总能量为U，功率为P，持续时间为t。由功率定义：

P = dU/dt
DeltaU = integral P(t) dt

恒定输出时：
DeltaU = P Delta t

代入 P = 10 kW，Delta t = 8 s：
DeltaU = 10000 x 8 = 80000 J
       = 80 kJ

量纲核对：[W] x [s] = [J]。

亮度描述视觉响应，温度描述热状态，功率表示能量传递速率。三者不能互相替代；输出总量还需对时间积分。

散页二：场能与尺度

假设：真空中的经典电磁场。电场强度记为E，磁感应强度记为B；总能量统一记为U，避免符号重用。

场能密度：
u = epsilon_0 E^2 / 2
  + B^2 / (2 mu_0)

epsilon_0：真空介电常数。
mu_0：真空磁导率。
[u] = J/m^3。

对球形区域积分：
U = integral_V u dV

若u可近似为常量，则：
V = 4 pi R^3 / 3
U = 4 pi R^3 u / 3

比较相同能量密度下的两个领域：
U_2 / U_1 = (R_2 / R_1)^3

R由25 m增至50 m时：
U_2 / U_1 = (50/25)^3 = 8

结论：维持相同场能密度，半径扩大两倍，储能需求扩大八倍。若总能量固定，平均能量密度降为原值的1/8。

散页三：边界通量

真空中的坡印廷矢量：
S = (E cross B) / mu_0
[S] = W/m^2

局域能量守恒：
partial_t u + div S = -J dot E

对固定体积V积分，并取边界外法线n：
dU/dt + integral_A S dot n dA
      = -integral_V J dot E dV

左侧第二项为净流出功率；右侧为物质对场做功的负值。J dot E > 0时，场向物质传能。

将外部供能另记为P_in，向外辐射记为P_out，内部吸收记为P_abs：

dU/dt = P_in - P_out - P_abs

稳定维持时 dU/dt = 0，故：
P_in = P_out + P_abs

旋转射线只能显示局部输运方向，不能推出球内能量密度处处相等。均匀覆盖还需指定源项分布与边界条件。

散页四：辐射输出

近似条件：发光表面处于热平衡，可采用黑体或灰体模型。

黑体辐射功率：
P = sigma A T^4

灰体与均匀环境交换时：
P_net = epsilon sigma A
        x (T^4 - T_env^4)

T、T_env均用开尔文。
0 <= epsilon <= 1。
sigma = 5.670374419e-8
单位：W/(m^2 K^4)。

球面面积 A = 4 pi r^2。
若 T 远大于 T_env，则：
P_net ~ 4 pi epsilon sigma r^2 T^4

保持r、epsilon不变：
P_2 / P_1 = (T_2 / T_1)^4

温度加倍，功率增至16倍。

反过来，保持功率与发射率不变：
r^2 T^4 = constant
T_2 / T_1 = sqrt(r_1 / r_2)

中心半径缩小一半，需要将绝对温度提高至原值的sqrt(2)倍，才可在上述近似下维持相同辐射功率。

散页五：空间衰减

假设点源各向同性、无介质吸收，且观测距离远大于源尺寸。取半径rho的球面：

P = I(rho) x 4 pi rho^2
I(rho) = P / (4 pi rho^2)

由此：
I(2 rho) / I(rho) = 1/4

该式用于自由传播的点源远场，不直接适用于聚焦光束或近场。

若仅考虑均匀吸收介质中沿程的衰减，吸收系数alpha为常量：

dI/dx = -alpha I
integral dI/I = -alpha integral dx
ln(I/I_0) = -alpha x
I(x) = I_0 exp(-alpha x)

其中 [alpha] = 1/m。

自由辐射不存在严格的有限截止半径。因此，领域内持续作用、领域外终止作用，须由灵力边界另行约束，不能由平方反比律直接得到。

散页六：光子数估算

单个光子的能量：
U_photon = h f = h c / lambda

h = 6.62607015e-34 J s
c = 299792458 m/s

取 lambda = 600 nm = 6.00e-7 m：
U_photon = (6.62607015e-34
            x 299792458) / 6.00e-7
         ~ 3.31e-19 J

若1 J能量全部由该波长的单色光构成：
N = U_total / U_photon
  = 1 / 3.31e-19
  ~ 3.02e18

检验：N为无量纲计数。

白色核心与橙红外晕用于区分聚能区和散逸区。视觉颜色不足以唯一确定光谱或温度；温度反演仍需发射模型与光谱数据。

散页七：热响应

条件：无相变，比热容c_p近似恒定，物体内部温度差可忽略。

Q = m c_p DeltaT
DeltaT = Q / (m c_p)

若吸收功率P_abs恒定，且短时散热可忽略：
Q = P_abs t
DeltaT = P_abs t / (m c_p)

量纲：
[J] / ([kg] x [J/(kg K)]) = [K]

出现相变时另计潜热：
Q_phase = m L

相变消耗的能量不能全部计入温升。

均匀介质中的扩散方程：
partial_t T = alpha_th laplacian T

按量级估算：
DeltaT / t ~ alpha_th DeltaT / l^2
l ~ sqrt(alpha_th t)

其中 [alpha_th] = m^2/s。
时间增至4倍，典型扩散距离约增至2倍。具体系数取决于几何形状与边界条件，材料厚度、湿度及散热项需分别给定。

末张：闭合条件

供能方程给出总量约束；坡印廷通量描述空间输运；吸收与热扩散决定介质响应。

尚需指定的量：
u(x,t)：场能密度分布。
P_in(t)：外部供能随时间的变化。
alpha(x)：介质吸收系数。
T(x,0)：初始温度场。
边界条件：领域表面的通量与灵力约束。

求解顺序：给定初始与边界条件，核对量纲，再计算储能、通量及吸收。稳态要求收支平衡；非稳态需保留dU/dt项。

有限范围、施法者保护与交战判定属于符卡规则，单独列项。它们不改变上述物理公式各自成立的前提。
